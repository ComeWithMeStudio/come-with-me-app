# Бібліотека Мімі

- `references/` — канонічні референси персонажа для створення ілюстрацій та анімацій.
- `blue-background/movement/` — наявні відео рухів Мімі.
- `illustrations/` — місце для майбутніх готових зображень Мімі (створюється з першим файлом): емоції, дії, основа для вдягання. Зберігати один раз для повторного використання в іграх.
