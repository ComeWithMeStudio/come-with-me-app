# Небесні пригоди Мімі

Five untimed activities based on the approved concept of 22 October 2026:

1. Choose the balloon, then raise it through three heights.
2. Choose the helicopter, then lift it vertically and hover over the pad.
3. Choose the red propeller airplane, then follow three cloud waypoints in order.
4. Choose the airship, then find a bridge, house and tree in any order.
5. Choose the passenger airplane, then fly to the illuminated night aerodrome.

Each chapter offers three choices; all five aircraft participate across the complete game. Wrong answers offer a gentle retry. Completion requires the child's action; chapters advance explicitly. The final screen includes all five aircraft and a restart.

Reuses the existing painted aircraft and day/night landscapes; rotor and propeller coordinates match the approved discovery. The airfield and river are CSS scenery; landmarks use emoji buttons. No generated bitmap assets were added.

Audio currently reuses the existing Gigi discovery narration, plus quiet daytime ambience (14%) and a soft completion chime. Night has no daytime ambience. All game-specific instructions are visible text. narration.json contains the twelve planned game-specific voice clips and established Gigi settings; these clips are NOT generated or wired yet.

Pause suspends Web Animations, CSS animation, audio and target interaction. Hiding the page pauses play; resumption is explicit. Wake lock is requested where supported. Reduced motion shortens travel while preserving each interaction. Pointer and keyboard activation use native buttons.
