# Будуймо з Мімі!

Перша інтерактивна версія, 22.10.2026. Меню: Розкажи мені → Пізнаваймо світ → Ігри.

Вісім етапів: бульдозер → екскаватор → самоскид → бетонозмішувач → автокран → навантажувач → асфальтоукладач → дорожній коток.

Кожен етап: вибір однієї з трьох машин, дія великою кнопкою, анімація роботи, перехід далі. Результати будівництва зберігаються. Після заливання бетону окремий перехід показує, що він затвердів. Кран ставить готовий модуль стін і дах. Перетягування не потрібне.

Графіка техніки: `/media/pograymo/assets/illustrations/transport/construction/`; нові фон, стіни, дах, пісочниця й самоскид зі щебенем — `assets/`. Дорога, фундамент, пісок і під’їзна доріжка — CSS. Мімі та квіти — наявні ілюстрації.

Озвучення завдань ще НЕ записане та НЕ підключене. Підказки текстові; звук правильного вибору — наявний `/audio/games/common/correct_chime.mp3`.

Перевірено в Chromium: усі 8 етапів до фіналу, неправильний вибір, повторний запуск із очищенням ділянки, зупинка й продовження анімації, відсутність помилок JavaScript та недоступних ресурсів. Переглянуті знімки екрана 390×844 і 1365×900. Тести проходження прискорені через prefers-reduced-motion, пауза перевірена зі звичайною тривалістю. На фізичному телефоні користувачки ще не перевірено.

Наступне: озвучення Gigi; перевірка рухів і композиції на фізичному телефоні та ноутбуці. Це тестова версія гри, не фінальна перевірена карта.
