# Полювання на фігури та кольори

Дві гри з діями поза екраном, по 4 рівні × 5 завдань. Основа — карти від 28.09.2026; реалізація для авторської перевірки 25.10.2026.

- `../hunting-shapes.html` — фігури; `../hunting-colors.html` — кольори.
- `tasks.js` — точні тексти, рівні та сталі ID всіх 40 завдань.
- `media.js` — точні шляхи шести наявних MIMI-DANCE відео на голубому фоні.
- `game.js`, `game.css` — спільний інтерфейс і переходи.
- `narration.json` — тексти для майбутнього запису Gigi; статус `pending_recording`. Озвучка завдань ще НЕ створена і не підключена. Наявна похвала береться з `/audio/games/common/correct-1.mp3` … `correct-5.mp3`.

Дитина або дорослий підтверджує виконання кнопкою «Готово!». Гра не перевіряє реальні предмети камерою. Після кожного підтвердження відтворюється наступний танець із шести (до 6,5 секунди); можна повторити або перейти далі. Прогрес враховує унікальні виконані завдання. Відкладені завдання не зараховуються; до них можна повернутися через вибір рівня. Перезапуск скидає прогрес. Автоматичного переходу або обмеження часу на пошук немає.

Зміни сценарію: «три кроки назад» замінено на «три кроки на місці». У пошуку кольорових предметів показується підказка знайти стільки, скільки є поруч. Початкові кількості з карт збережено. Фігури малюються SVG з чіткими кутами; кольори мають текстові підписи.

Каталог показує картки цих версій тільки в наявному режимі автора (`?preview=alona`). Це спосіб сховати незавершену версію з загального меню, не механізм захисту доступу. Прямі HTML-посилання доступні. Існуючі екранні ігри «Знайди фігуру» та «Знайди колір» не змінені.

Перед повним випуском: записати й перевірити озвучку інструкцій; пройти обидві гри з дитиною на телефоні та ноутбуці.
