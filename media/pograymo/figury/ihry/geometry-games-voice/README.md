# Майстерня фігур — озвучення

Сюди завантажувати **розпаковані MP3**, не ZIP.

- `00-intro.mp3` — короткий вступ
- `01.mp3` … `20.mp3` — репліки для 20 конструкцій у порядку гри
- `21-finale.mp3` — короткий фінал

Файл `transcript.json` містить тексти реплік.

Після завантаження файлів потрібно окремо підключити відтворення в `../geometry-games.html`, перевірити звук на телефоні та ноутбуці. Наявність MP3 сама по собі не запускає озвучення.
