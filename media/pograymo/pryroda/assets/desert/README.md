# Тварини пустель

15 окремих ілюстрацій для Come With Me Studio. Формат WebP, прозоре тло, одна тварина в кожному файлі.

Добірка об’єднує тварин пустель і напівпустель різних частин світу. Розміри ілюстрацій не передають реальні співвідношення розмірів тварин.

Ілюстрації створено вбудованим генератором зображень; під час конвертації PNG → WebP збережено альфа-канал. Спільний опис стилю: доброзичлива, м’яко стилізована 3D-ілюстрація тварини на повний зріст, природні пропорції, деталізована поверхня, прозоре тло, без написів, декорацій та аксесуарів.
