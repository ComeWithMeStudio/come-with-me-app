# Пограймо → Природа → Водні мешканці

16 окремих ілюстрацій: 10 риб, косатка, тюлень, восьминіг, дельфін, морська черепаха та медуза.

WebP, 1024 × 1024, справжній альфа-канал. Малюнки центровані з прозорими полями. Назви й шляхи наведено в `asset-registry.json`.

Стиль узгоджено з оглядом 90 наявних PNG/WebP у застосунку: м’яка об’ємна дитяча ілюстрація, виразні очі, насичені кольори. Створено вбудованим генератором зображень. Це бібліотека ілюстрацій; підключення до екранів ігор виконується окремо.
