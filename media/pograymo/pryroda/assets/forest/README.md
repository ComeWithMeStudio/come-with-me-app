Кожна тварина — окремий файл, без підставки та декорацій. У наборі є мешканці лісів, узлісь і лісових водойм. Це тематична добірка, а не твердження, що всі види трапляються в кожному лісі.

Олень зображений із розгалуженими рогами, лось — із лопатоподібними, козуля — самиця без рогів. Сова сіра представлена бурою формою забарвлення. Масштаб окремих ілюстрацій не відображає реального співвідношення розмірів тварин.
