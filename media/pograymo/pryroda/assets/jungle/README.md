# Мешканці джунглів

Колекція об’єднує мешканців тропічних лісів різних континентів та прилеглих водойм і вологих територій (капібару). Це тематична добірка, а не тварини одного спільного місця проживання. Масштаб ілюстрацій не відображає реальні співвідношення розмірів тварин.
