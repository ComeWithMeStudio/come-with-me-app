# Технічна пам'ять ігор Come With Me Studio

Створено 2026-11-11. Це **довідник**, а не інструкція змінювати застосунок автоматично.

## Навіщо
Перед розробкою нової гри знайти аналогічні реалізації та минулі помилки; після тестування зберегти перевірене рішення. Не плутати ідеї, спостереження, гіпотези та підтверджені виправлення.

## Статуси записів
- **Підтверджено** — є конкретний код/коміт, відтворювані кроки і перевірка результату.
- **Спостереження** — проблему бачили, але причина ще не доведена.
- **Гіпотеза** — можливе пояснення, яке треба перевірити.
- **Не працює** — невдала спроба, збережена, щоб не повторювати.
- **Застаріло** — рішення більше не відповідає поточному коду.

## Шаблон картки
1. Назва гри / категорія; дата; автор перевірки.
2. Симптом або мета; очікувана й фактична поведінка.
3. Середовище: браузер, пристрій, версія застосунку.
4. Кроки відтворення.
5. Що пробували: успішні й невдалі підходи.
6. Точне рішення: шляхи файлів, посилання на коміт/PR, потрібні налаштування.
7. Як перевірили: телефон/ноутбук, звук, переходи, фінал.
8. Статус і відкриті питання.
9. Посилання на відповідну картку Google Drive.

## Початковий перелік тем для перевірки
Це **не підтверджені технічні рішення**; заповнити після перегляду коду та тестів:
- «Місток»: порядок шарів метелика й трави.
- «Хованки»: українська вимова та переходи між сценами.
- «Розмальовка»: заливка, пензлик, гумка, переходи.
- «Годинник»: рівні, години та хвилини.
- «Конячка біжить»: перешкоди, керування, звуки.
- Аудіорепліки ігор: завантаження та відтворення, R2/S3 лише після підтвердження налаштувань.

## Правило для розробника / Codex
1. Прочитати цей файл перед новою грою або складним виправленням.
2. Перевірити релевантні приклади в коді; не вважати спогади доказом.
3. Не змінювати секрети, платежі, дозволи, публікації або продакшн без окремого погодження.
4. Після підтвердженого тесту доповнити картку; не переписувати історію невдалих спроб.
5. Не записувати паролі, токени, приватні URL із секретами або особисті дані.

Google Drive містить людський довідник; GitHub — точні технічні посилання. Уникати дублювання великих фрагментів коду.
