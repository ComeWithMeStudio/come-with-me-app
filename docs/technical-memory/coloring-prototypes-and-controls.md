## Уроки для наступних ігор
1. Відокремлювати перевірку інструментів (пензлик, заливка, гумка) від художніх правок конкретної сцени.
2. Тестувати кожну ілюстрацію окремо, перш ніж переносити її в основний каталог.
3. Під час перемальовування не переписувати без потреби вже перевірені елементи керування.
4. Фіксувати окремо: «прототип існує», «механіка перевірена», «ілюстрація схвалена», «інтегровано в застосунок».

## Що залишається відкритим
Ці коміти самі по собі не доводять, що всі прототипи інтегровані в кінцеву гру або що користувачка прийняла кожну ілюстрацію. Потрібні окремі результати перевірки на телефоні й ноутбуці.

Джерела: коміти GitHub, наведені вище. Це документування, без зміни ігор.
