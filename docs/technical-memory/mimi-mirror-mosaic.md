# Дзеркальна мозаїка Мімі
Дата: 13.11.2026. Статус: опубліковано; повний цикл перевірено в Chrome, очікує перевірки Альони. Не затверджено Альоною.

Перед вибором прочитано поточний README та технічну пам'ять, код ігор фігур, каталог, дерево ресурсів і останній коміт. На Drive перевірено кореневу папку, Вхідні, плани, ідеї та роботи; прочитано реєстр майбутніх ігор та карту Каляк-маляк. Мозаїка — окремий задум про дзеркальну симетрію, не реалізація цих карт.

Два рівні по 8 візерунків (2×2 та 3×3 на кожній половині). Обрати фігуру → поставити у клітинку справа. Гумка очищає клітинку. Перевірка не стирає спробу. Підказка підсвічує правильну пару. Є ручні переходи, вибір рівня, фінал 16/8, повтор, вихід. Порядок завдань і палітри перемішується. Фігури мають різні форму й колір.

Оригінальний /mimi-home.png; точна SVG-мозаїка, без генерації ілюстрацій. 5 нових реплік Gigi з активного власного ElevenLabs через Composio. Тексти й параметри narration.json. Нових покупок немає. MP3 повністю декодовано FFmpeg; це не слухова перевірка української вимови.

Каталог фігур доповнено без вилучення старих карток. Додано лише новий шлях до чинного списку paidPaths, використано наявний режим автора; оплати й дозволи не змінювалися.

## Перевірки
node --check game.js успішний. Результати браузера будуть дописані після фактичного проходження.

## Попередня гра
Терези Мімі: основний цикл уже перевірений 12.11. У повторному тесті 13.11 реальне перемикання вкладки кліком теж не зупинило музику. Вимкнення звуку працює. Причина не встановлена. Потрібна окрема перевірка lifecycle у звичайному браузері/телефоні; не вважати цей крайовий випадок виправленим.

## Фактичний результат 13.11.2026
- Коміт реалізації: https://github.com/ComeWithMeStudio/come-with-me-app/commit/e8cca9397b3f22284600ff684705200e6b1a18a0
- Pages run 43343444673 успішний. Початковий 404 спостерігався до завершення публікації, після успіху нова сторінка відкрилася.
- Повний цикл 16/16 пройдено через реальні кнопки в широкому Chrome та iframe шириною 390 CSS px. Перехід після 8-го візерунка показує окремий екран; фінал — 16.
- Окремий рівень 1 пройдено 8/8 на широкому екрані; окремий рівень 2 — 8/8 на 320. У фіналі окремого рівня написано 8. Повтор, вибір рівня, повернення в каталог і вхід із нової картки перевірені.
- Неправильна відповідь залишає спробу; підказка виділяє дзеркальну пару; гумка повертає клітинку до стану «порожньо». Перевірено повторне редагування.
- На 320/390/768/1280 px scrollWidth==clientWidth. Це iframe/CSS-розміри у Chrome, не фізичні Android/iOS.
- Знайдено 38.3 px клітинки при iframe320; ущільнено зовнішні відступи лише до 350 px. Коміт 63bece4db31cabe26a2d772ea17869465890a3ed; Pages run 43344123086 успішний. Після hard reload підтверджено style.css?v=20261113-2, клітинки 44.65–44.67 px та відсутність горизонтального прокручування. На оновленій версії повторно пройдено рівень 2 8/8 на 320.
- Важлива невдала перевірка: звичайний reload стенду спершу залишив старий iframe HTML із style.css?v=20261113-1. Це не відсутність коміту; після примусового оновлення видно v2. Перед вимірюванням перевіряти фактичну версію ресурсу.
- Запуск вступу, правил другого рівня, повтору правил, підказки та фіналу підтверджено через readyState=4 / paused=false / currentTime>0; музика відтворюється, на фіналі пауза. Кнопка «Звук: вимкнено» зупиняє всі чотири audio. Це технічний запуск, не слухове схвалення наголосів.
- Усі 5 нових MP3 завантажено з опублікованої сторінки, звірено побайтово з локальними й повністю декодовано FFmpeg. Наявні Mimi PNG, спільна музика, похвала і сигнал також декодовані.
- node --check та XML SVG успішні; усі 16 шаблонів перевірено на розмір/непорожність, потребу у віддзеркаленні, збереження рядків і зворотність координат.
- Знімки: docs/qa/mosaic-wide.jpg, mosaic-mobile-390.jpg, mosaic-mobile-320.jpg, mosaic-cover.jpg; стенд docs/qa/mosaic-viewports.html.
- Каталог містить нову картку та всі 8 попередніх; жодну не замінено. Зміна game-access.js — тільки додавання нового шляху до paidPaths. Повне повторне проходження всіх старих ігор не проводилося.
