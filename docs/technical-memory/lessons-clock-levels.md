## Технічна шпаргалка
Файл: `media/rozkazhy-meni/pryhody-mimi/hodynnyk-mimi/index.html`
- Під час поділу на рівні узгоджувати масив `rounds`, кількість завдань на рівень і максимальне значення індикатора прогресу.
- Для запуску конкретного рівня використовувати явні межі `startIndex` / `endIndex`, а не припускати, що гра завжди стартує з нуля.
- Відокремити стан переходу між рівнями від стану завершення гри (`transition`, `finished` у зафіксованому коміті).
- Перевірити режими «Уся гра», «Рівень 1», «Рівень 2», зокрема останнє завдання та перехід.
