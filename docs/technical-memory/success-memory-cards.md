# Успіх: «Запам'ятай з Мімі» — картки тварин
Дата ретроспективи: 2026-11-11
Статус: **підтверджено історією комітів**, але не новим тестом на пристрої.

## Що вдалося повторно застосувати
Гра використовує окремі файли `index.html`, `game.js`, `style.css`, `items.json`. Дані карток відокремлені від логіки, а відображення картинок використовує SVG viewBox та координати кадрування.

## Конкретні кроки, зафіксовані в історії
1. Змінити склад карток через `items.json`, якщо персонаж невиразний або погано вписується в рамку.
2. Підтримувати узгоджені зміни в `game.js` і `index.html`, коли змінюються картки чи інструкції.
3. Перевірити розміри карток на мобільному екрані; зміни стилів внесені в `style.css`.
