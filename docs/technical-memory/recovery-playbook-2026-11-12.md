## 1. Порожній автобус — підтверджене виправлення
«Літерна пошта», 12.11.2026. city-bus-yellow.webp повертав HTTP 200 і мав naturalWidth, але картинка була порожньою; Pillow та FFmpeg не декодували файл. Повторне завантаження тієї ж пошкодженої картинки не є виправленням.
Створено окремий assets/bus-v2.webp, оновлено лише посилання цієї гри. Спільний оригінал не затирали. Візуальний результат перевірено у Chrome.
Урок: завантаження, декодування й відображення — три окремі перевірки.
Деталі: [Літерна пошта](letter-post-media-and-qa.md).
Коміт: https://github.com/ComeWithMeStudio/come-with-me-app/commit/8b9a35cc127c253f9b876d3937c419ea02e2b84c

## 2. GitHub ≠ опублікований сайт — підтверджений збій, причина не встановлена
У job 129554335788 журнал від 10.11.2026 показує deployment_queued → syncing_files → Timeout reached, aborting! приблизно через десять хвилин. Збірка й публікація — окремі етапи.
Повторний запуск невдалих jobs був виконаний 11.11; тоді підтверджено лише чергу. Пізніші Pages-запуски успішні, оновлені кнопки й аудіо видно на сайті 12.11. Не доведено, що саме повтор усунув першопричину.
Порядок наступного разу: знайти коміт → перевірити build і deploy → прочитати помилку jobs → за доречності повторити невдалий етап → перевірити конкретну версію живої сторінки та ресурси. Після кешування перевірити новий URL версії або виконати звичайне примусове оновлення. Не перегенеровувати голос і не міняти авторизацію лише через стару сторінку.
Невдалий запуск: https://github.com/ComeWithMeStudio/come-with-me-app/actions/runs/42732569713
Успішна наступна публікація: https://github.com/ComeWithMeStudio/come-with-me-app/actions/runs/43132502610

## 3. Кнопки й картки на телефонній ширині — підтверджено у Chrome
У «Терезах» правильна відповідь зараховувалася, але наступна кнопка могла опинитися нижче видимої частини iframe; автоматизований клік не проходив. Після показу кнопки додано next.focus(). Перевірено всі 16 завдань на 390 CSS px: кнопка стає активним елементом, далі можна пройти до фіналу.
У «Літерній пошті» обгортки з окремими кнопками озвучення розкладали картки як 2+1. Для вузького екрана змінено flex-розміри, збережено доступні назви та 44 px для звукових кнопок. Три варіанти видно одним рядом.
Перевірки 320/390/768/1280 px — це браузерні розміри, не фізичні Android/iOS.
Коміт фокуса: https://github.com/ComeWithMeStudio/come-with-me-app/commit/49ec8da80f9d1625dc5feb4b7a3d9cd7892e9c56
Деталі: [Терези](mimi-scales.md), [Літерна пошта](letter-post-media-and-qa.md).

## 4. ElevenLabs — робочий шлях підтверджено 12.11.2026
Старі невдалі підтвердження доступу 29.10 зберігаються як окремий випадок із невстановленою причиною. Їх не слід повторювати за інерцією.
Поточний успішний ланцюжок: активне власне підключення ElevenLabs у Composio → ELEVENLABS_TEXT_TO_SPEECH → результат data.file.s3url → завантаження MP3 → повне декодування FFmpeg → GitHub blob/tree/commit → URL у коді → перевірка відтворення в грі.
П'ять незалежних коротких реплік згенеровано одним пакетом, усі п'ять повернули успіх. Тимчасові URL не зберігати в довіднику: вони спливають і можуть містити підпис доступу.
Gigi, multilingual_v2, stability .65, similarity .23, style .43, speaker boost. Тексти й параметри лежать у narration.json гри. Синтез через підключений інструмент підтверджений; окремий прямий HTTP-доступ із довільного скрипту не перевірявся.
Доказ файлів: https://github.com/ComeWithMeStudio/come-with-me-app/commit/e9f6b961566b59031f5a70a88ffa3dc45df2b4e8
Деталі: [ElevenLabs](elevenlabs-access-and-narration.md).
Не ототожнювати декодування або paused=false з правильністю наголосу: потрібне прослуховування.

## 5. Звук при згортанні — частковий успіх, відкрита перевірка
У «Терезах» вимкнення звуку зупиняє всі audio. window.blur додано до visibilitychange/pagehide.
Перевірено в стенді: перехід фокуса з гри до зовнішнього комбобокса зупинив голос і музику; «Послухати» відновило обидва. Але Alt+4/Alt+5 у керованому Chrome паузу при перемиканні вкладок не підтвердило. Причина не встановлена. Не переносити частковий успіх на всі пристрої.
Наступна перевірка: окремо вкладка браузера, згортання застосунку, блокування телефона; перевіряти голос і музику, потім повернення й повтор.
Коміт: https://github.com/ComeWithMeStudio/come-with-me-app/commit/769f795517eb93548daa672ff9808c6ee95d2bed

## 6. Локальний браузер недоступний — робочий обхід перевірено
Локальний Chromium завершувався з socket() failed: Operation not permitted. Повторний запуск тим самим шляхом не дав браузера.
Використано спільний Chrome для реальних натискань і проходження. Окремі HTML-стенди з iframe дозволили оглянути різні ширини без доступу до DevTools.
Це обхід конкретного обмеження запуску, не доказ проблеми сайту чи акаунта. Не послаблювати системні обмеження й не називати весь браузерний тест недоступним, поки є дозволений робочий інструмент.
Стенди: docs/qa/letter-post-viewports.html, docs/qa/scales-viewports.html.
