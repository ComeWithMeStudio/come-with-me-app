# Чарівна розмальовка — погоджений план

Оновлено: 2026-11-02. Статус: погоджено користувачкою; функції, позначені як заплановані, ще не реалізовані.

## Сім сцен у порядку
1. Казковий метелик — перевірено на телефоні.
2. Квіточка та їжачок — перевірено на телефоні.
3. Кошеня з повітряними кульками — перевірено на телефоні.
4. Будиночок із цуценям — перероблена версія чекає остаточного тесту.
5. Черепашка замість сонечка — заплановано.
6. Рибка — заплановано.
7. «Моя творчість» — чистий аркуш, на якому дитина малює будь-що самостійно; обов’язкова остання сцена.

## Погоджені можливості
- У всіх готових розмальовках дитина може не лише заливати кольором, а й домальовувати власні деталі пензликом (приклад із тесту Міри: дим із димаря).
- Інструменти: заливка, пензлик, гумка для мазків пензлика, скасування останньої дії, очищення. Гумка не стирає заливку; колір заливки змінюється повторним натисканням іншого кольору.
- На чистому аркуші — пензлик, гумка, скасування, очищення; за потреби додаткові інструменти.
- **Заплановано:** кнопка «Зберегти малюнок» на кожній із семи сцен. Збереження у PNG на пристрій без серверного сховища; перевірити роботу на Android та ПК.
- **Заплановано:** перехід між сценами без повернення в головне меню.
- **Заплановано:** короткі українські голосові підказки, після завершення малюнків та тестування інструментів.

## Чернетки реплік для озвучення (погоджений задум)
- Для готових сцен: «Розфарбуй малюнок у свої улюблені кольори! А хочеш — домалюй щось своє. Тут можна фантазувати!»
- Для останньої сцени: «А тепер ти — справжній художник! Перед тобою чистий аркуш. Намалюй усе, що підкаже твоя уява. А потім збережи свій шедевр!»

## Принципи
- Великі, зручні для заливки замкнені області; милі персонажі та сюжет, а не лише геометричні предмети.
- Не ламати вже перевірені сцени під час додавання нових можливостей.
- Зміни на GitHub не вважати перевіреними на телефоні, доки користувачка не підтвердить тест.
